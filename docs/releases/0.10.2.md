# 0.10.2

减少长回复因独立标点和译文首尾空白而整条翻译失败的情况。

- 独立标点、符号和表情由本地原样保留。译文首尾的多余空白会去掉，正文中新增的换行和表格分隔符仍会触发校验。
- 补译只请求未通过的正文片段，并按校验原因给出修正提示。补译后仍失败时保留整条原文。
- 可复制的 `TR_SEGMENT_INVALID` 报告新增 `segmentRejected`，按原因统计最后一次响应中的拒绝记录。报告只包含计数和现有诊断字段。

本地通过 443 项测试、插件严格校验和 TypeScript 检查。真实 Codex CLI 一次完成了模拟长回复的翻译，保留了 51 行结构和全部保护内容。

更新后请完整退出并重启 Claude Code，再恢复会话重新翻译。
