# 0.9.0

选择面板现在独立自动翻译，无需将助手回复改成全部自动翻译。

- 通过原生 `AskUserQuestion` 事件识别选择面板，在普通终端和全屏界面中自动翻译问题正文、页签、选项译名和说明。
- 与 `output_trigger=manual / final / auto` 独立。继续使用 `final` 时，过程回复保持手动、最终答复自动翻译，选择面板也自动翻译。
- 面板上方显示翻译进度。复用有界队列、缓存与并发限制，重绘不会重复请求；关闭或取消面板会丢弃过期结果。
- 选项原始名称、提交值、顺序和预览保持一致；中文译名显示在选项说明中。原生按钮和宿主确认面板不改写。
- 翻译失败保留原面板和诊断。全屏可重试／复制；普通终端显示可手动复制的错误摘要。

需要先阅读译文时，请等待面板翻译完成再开始选择或输入；宿主可能固定已经交互的面板以保护当前选择。

验证：407 项测试、严格校验和 TypeScript 检查通过。使用离线翻译后端在真实普通终端面板中验证了 `final` 下的自动翻译，确认只调用一次翻译、提交值仍是原始选项名称。

更新后请完整退出并重新启动 Claude，可用 `claude --resume <会话 ID>` 恢复原会话。
