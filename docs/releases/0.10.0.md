# 0.10.0

路径和代码由程序留在本地，再与译文拼合，模型无需抄回保护标记。修复长回复因模型漏返一个标记而整段翻译失败的问题。

- 输入、回复、选择面板共用编号正文块协议；路径、URL、行内代码、代码块和响应边界由本地程序按原顺序保留，纯保护内容无需后端请求。
- 缺失或冲突的正文块最多补译一次，只请求未解决的编号，保留已通过的译文。一次翻译最多处理 512 个正文块；补译失败继续保留原文。
- Codex 翻译和补译共用 `codex_timeout_seconds` 等待预算，补译只使用剩余时间；不自动重试网络、进程和服务错误。
- 补译后仍不完整显示 `TR_SEGMENT_INVALID`。错误摘要升级为 `reportVersion: 2`，增加正文块预期、有效、未解决、重复、未知记录数量，不包含正文或译文。
- 保留选择面板自动翻译、原始选项提交值，以及取消、队列、历史和显示模式的规则。

此机制保证本地保护内容不依赖模型复制；结构检查不能保证自然语言没有误译或语义上的漏译。

验证：426 项测试、严格校验和 TypeScript 检查通过。真实 Codex CLI 分别翻译此前的长回复（25 段保护内容）与含 34 段保护内容的测试文本，两次均一次成功并保留全部保护内容。离线后端的真实普通终端面板验证了自动中文显示、一次翻译请求和原始选项值提交。

更新后请完整退出并重新启动 Claude，以确保当前会话加载新代码；可恢复原会话继续使用。
