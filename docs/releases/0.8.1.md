# 0.8.1

细化 `TR_TEXT_INVALID` 的诊断，并加强路径／代码保护标记的翻译要求。

- 输入和回复翻译在保护标记校验失败时显示预期数、收到数、缺失数、重复数及未知／格式错误数；复制错误信息也包含这些数量，不包含原文、路径、代码或译文。
- 翻译提示词附带保护标记清单并要求逐个检查；较大清单使用有界的索引范围，避免指令无限增长。
- 标记校验改为线性扫描，全部校验通过后才一次恢复原始路径和代码。缺失、重复、格式错误及未知标记仍严格拒绝，不做猜测替换，不自动追加翻译请求。

针对报告中的原文，使用原配置独立重跑及 Claude 原生进程接口复测均保留全部 25 个标记。原失败译文未保存，尚未确定其具体损坏方式，因此此版本不宣称已消除所有同类失败。若更新后仍失败，请复制新的错误信息用于继续排查。

验证：391 项测试通过，严格校验及 TypeScript 检查通过。额外执行了同文真实 CLI 和 Claude 原生进程接口验证。
