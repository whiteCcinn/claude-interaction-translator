# 0.10.1

修复长回复翻译后正文被清空、表格和列表消失，只剩路径／代码拼接的问题。旧版允许同一字段内搬移正文和返回空片段，只要整条回复还剩一点正文就可能通过校验。

- 每个非空正文片段独立校验，拒绝空白、只有标点的正文、明显异常缩短的译文，以及片段内新增的结构分隔符。
- 换行、表格分隔符、标题／列表前缀和加粗等分隔符由本地保留。多行／Markdown 纯正文也采用结构化翻译。
- 请求只包含独立的编号片段；不再附整篇回复作为上下文，大批量片段打散后发送，减少模型跨片段改写。原位置和保护内容由程序按编号恢复。
- 最多补译一次，只处理无效片段；仍不合格时保留整条原文，并提示 `TR_SEGMENT_INVALID`。共用超时、取消、队列和历史规则保持有效。

逐片段翻译有时比整句翻译生硬。完整性检查能拦截正文清空和结构坍塌，不能证明任意自然语言的语义没有漏译或误译。

验证：440 项测试、严格校验和 TypeScript 检查。真实原文的 56 行、表格／列表及 44 处保护内容均保留；真实 CLI 使用现有 gpt-6-luna / low / Fast off 设置。会话及模型响应不进入仓库。

更新后请完整退出并重新启动 Claude，确保会话加载修复代码；可恢复原会话继续使用。
