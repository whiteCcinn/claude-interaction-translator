# 0.8.0

翻译等待时长现在可以配置；失败提示会显示具体原因，并支持复制诊断摘要用于排查。

- 新增 **Codex translation timeout (seconds)**（`codex_timeout_seconds`），默认 120 秒，可设为 1～600 秒的整数。输入、回复和选择面板的 CLI 翻译均生效；API 后端不使用此设置。
- 失败提示显示固定错误码，区分 CLI 超时、异常退出、空输出、输出截断、译文校验失败，以及 API 请求、HTTP 状态、响应和长度限制等错误。
- 新增 **复制错误信息 / Copy error**，复制后端、失败阶段、可用耗时、超时设置及状态码／退出码。摘要不含正文、译文、凭据、接口地址、模型、文件路径或原始服务日志，不会自动上传。
- 紧凑终端保留错误原因和复制入口；重试立即清除旧错误，多条回复分别对应自己的诊断信息。
- 更新 CI 验证基线至 Claude Code 2.1.325，并同步测试夹具以适配其类型声明。

更新后，在 Claude 会话中运行 `/reload-plugins`，或重启 Claude。需要延长等待时长时，在插件配置中将 **Codex translation timeout (seconds)** 设为 300 或 600，保存后再次重新加载插件。

验证：378 项测试通过，整包严格校验及 TypeScript 检查通过。测试使用模拟后端，不调用真实翻译服务。
